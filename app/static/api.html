Primii pași

Căutați un indicator, citiți structura setului de date, apoi cereți doar rândurile de care aveți nevoie.

# 1. Caută (întrebare obișnuită sau cuvinte cheie)
curl "https://api-ins.gov2.ro/api/search?q=rata+somajului&lang=ro"

# 2. Structura unui set de date: dimensiuni, valori, definiție, perioadă
curl "https://api-ins.gov2.ro/api/datasets/POP107A?lang=ro"

# 3. Date: filtre și grupare ca JSON (codificat în URL)
curl -G "https://api-ins.gov2.ro/api/datasets/POP107A/data" \
  --data-urlencode 'filters={"REF_AREA":["Cluj"],"TIME_PERIOD":["2024"]}' \
  --data-urlencode 'limit=100'

Toate rutele acceptă lang=ro (implicit) sau lang=en. Lista completă, cu toți parametrii: referința interactivă.

Cum citiți un răspuns de date

  • truncated: true înseamnă că ați primit doar o parte din rânduri. Nu faceți clasamente sau totaluri din ele: filtrați mai strict sau grupați.
  • unavailable: true și aggregation.reason înseamnă că totalul cerut nu se poate calcula sigur (niveluri suprapuse, ponderi lipsă, o sumă pe care INS o contrazice). Nu îl calculați singuri din rândurile brute.
  • generation.id identifică versiunea datelor. Păstrați-l lângă orice cifră pe care o publicați.
  • O coloană sau un filtru necunoscut produce eroarea 400; parametrii greșiți nu sunt ignorați în tăcere.

Server MCP (pentru asistenți AI)

Adresa: https://api-ins.gov2.ro/mcp (Streamable HTTP, doar citire, fără cheie). Adăugați-o ca conector personalizat:

  • Claude (testat): Settings → Connectors → Add custom connector. În Claude Code: claude mcp add --transport http ins-tempo https://api-ins.gov2.ro/mcp
  • ChatGPT (netestat încă): Developer mode → Add custom MCP server, pe planurile plătite.
  • Alți clienți: orice aplicație care acceptă servere MCP la distanță prin HTTP.
  • Instrucțiuni pentru fiecare client: Gemini, Grok, Cursor, VS Code, Codex, OpenCode, API-uri și altele.

Unelte: discover_indicators, describe_dataset, find_dimension_values, query_data, compare_periods, rank_entities, run_recipe, get_evidence_links. Serverul nu apelează niciun model și nu rulează SQL sau cod. Fiecare rezultat își declară sursa, definiția, unitatea, perioada și generația datelor.

Ce înregistrăm: argumentele trimise uneltelor și rezultatele lor, fără adresa IP și fără identitatea clientului, ca să îmbunătățim răspunsurile. Nu trimiteți date personale sau confidențiale.

SDMX 2.1

GET /sdmx/2.1/data/INS,{cod}?startPeriod=2020&endPeriod=2024
GET /sdmx/2.1/datastructure/INS/{cod}/1.0
GET /sdmx/2.1/dataflow/INS/{cod}/1.0

Răspunsurile sunt XML (SDMX-ML). Codul fluxului este codul setului de date, de exemplu ACC102B.

Limite și utilizare corectă

  • Serviciul este gratuit și în versiune alfa. Nu garantăm disponibilitatea; rutele marcate aici pot primi câmpuri noi, dar nu își schimbă sensul fără anunț.
  • Fiecare adresă IP are o limită de cereri. Dacă primiți răspunsul 429, așteptați câteva secunde și reîncercați.
  • O cerere de date întoarce cel mult 50.000 de rânduri. Seturile mai mari cer cel puțin un filtru.
  • Pentru volume mari, descărcați fișierele (CSV/XLSX), nu cereți rând cu rând.
  • Citați sursa: „Sursa: INS, TEMPO Online; prelucrare INS+ (ins.gov2.ro)”.

API and MCP

INS+ data is available to code and to AI assistants: free, with no account and no key, read-only. The rules are the same as on the site: a total that cannot be computed safely is refused, not guessed.

Quick start

Search for an indicator, read the dataset's structure, then ask only for the rows you need.

# 1. Search (a plain question or keywords)
curl "https://api-ins.gov2.ro/api/search?q=unemployment+rate&lang=en"

# 2. A dataset's structure: dimensions, values, definition, period
curl "https://api-ins.gov2.ro/api/datasets/POP107A?lang=en"

# 3. Data: filters and grouping as JSON (URL-encoded)
curl -G "https://api-ins.gov2.ro/api/datasets/POP107A/data" \
  --data-urlencode 'filters={"REF_AREA":["Cluj"],"TIME_PERIOD":["2024"]}' \
  --data-urlencode 'limit=100'

Every route takes lang=ro (default) or lang=en. The full list, with every parameter: interactive reference.

How to read a data response

  • truncated: true means you received only part of the rows. Do not rank or total them: filter more tightly, or group.
  • unavailable: true with aggregation.reason means the requested total cannot be computed safely (overlapping levels, missing weights, a sum INS contradicts). Do not compute it yourself from the raw rows.
  • generation.id identifies the data version. Keep it next to any number you publish.
  • An unknown column or filter returns a 400 error; wrong parameters are never silently ignored.

MCP server (for AI assistants)

Endpoint: https://api-ins.gov2.ro/mcp (Streamable HTTP, read-only, no key). Add it as a custom connector:

  • Claude (tested): Settings → Connectors → Add custom connector. In Claude Code: claude mcp add --transport http ins-tempo https://api-ins.gov2.ro/mcp
  • ChatGPT (not tested yet): Developer mode → Add custom MCP server, on paid plans.
  • Other clients: any app that supports remote MCP servers over HTTP.
  • Setup for each client: Gemini, Grok, Cursor, VS Code, Codex, OpenCode, APIs and more.

Tools: discover_indicators, describe_dataset, find_dimension_values, query_data, compare_periods, rank_entities, run_recipe, get_evidence_links. The server never calls a model and never runs SQL or code. Every result states its source, definition, unit, period and data generation.

What we record: the arguments sent to the tools and their results, without the IP address or client identity, to improve the answers. Do not send personal or confidential information.

Limits and fair use

  • The service is free and in alpha. Availability is not guaranteed; the routes listed here may gain fields, but do not change meaning without notice.
  • Each IP address has a request limit. If you receive a 429 response, wait a few seconds and retry.
  • A data request returns at most 50,000 rows. Larger datasets need at least one filter.
  • For large volumes, download files (CSV/XLSX) instead of paging row by row.
  • Cite the source: “Source: INS, TEMPO Online; processed by INS+ (ins.gov2.ro)”.
